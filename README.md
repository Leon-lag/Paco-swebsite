# Paco's Tacos of Ogden

Restaurant website for Paco's Tacos of Ogden — authentic Mexican flavors in Marriott-Slaterville, UT.

Built with Next.js, React, and Tailwind CSS. Exports as a static site.

## Getting Started

```bash
npm install
npm run dev
```

Open https://out-qzsdmixp.devinapps.com/contact 

## Build

```bash
npm run build
```

Static output is generated to `./out`.

## Pages

- **Home** — Hero, quick info, menu preview, featured reviews
- **Menu** — Categorized menu items
- **Reviews** — Customer reviews with rating breakdown
- **Contact** — Location map, phone, hours, directions

## Customization

- `src/lib/brand.ts` — Restaurant info (name, address, phone, hours)
- `src/lib/menu.ts` — Menu categories and items
- `src/lib/reviews.ts` — Customer reviews and highlights
